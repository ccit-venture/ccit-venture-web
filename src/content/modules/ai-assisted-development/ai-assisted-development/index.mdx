## Tentang Kurikulum Ini

Kurikulum ini adalah **jalur developer dengan bantuan AI** untuk kamu yang ingin langsung memakai AI agent membuat file dan aplikasi, bukan cuma bertanya-tanya lewat chat. Setiap tutorial berdiri sendiri, jadi kamu bisa memilih alat yang paling cocok dengan perangkat dan budget kamu:

| Sesi | Alat | Kamu akan bisa |
|------|------|----------------|
| 1 | **OpenCode** | Pasang OpenCode lewat npm, hubungkan API Key OpenCode Zen, lalu minta AI membuat halaman web di dalam folder proyek |
| 2 | **Google Gemini** | Ambil API Key dari Google AI Studio, pasang Gemini CLI, dan minta Gemini membuat serta menyimpan file HTML |
| 3 | **9Router** | Hubungkan banyak provider AI gratis (termasuk Gemini) lewat 9Router ke satu endpoint lokal, lalu pakai dari OpenCode |
| 4 | **freebuff** | Pakai AI agent gratis tanpa token sama sekali lewat CLI atau aplikasi desktop, cukup login dan minta kode |

**Catatan penting:** AI adalah *partner*, bukan mesin jawaban. Selalu baca dan pahami hasil yang dibuat AI sebelum kamu pakai, dan jangan pernah menempelkan API key atau token ke dokumen publik.

## Cara Pakai Kurikulum Ini

- Kalau kamu **pemula total**, mulai dari Sesi 2 (Gemini) karena paling sedikit konfigurasinya, cukup browser dan akun Google.
- Kalau kamu mau **coba CLI AI agent**, lanjut ke Sesi 1 (OpenCode).
- Kalau mau **gabungan banyak model gratis sekaligus**, ikuti Sesi 3 (9Router) setelah punya API key Gemini dari Sesi 2.
- Kalau mau yang **tanpa token sama sekali**, langsung coba Sesi 4 (freebuff).

Semua sesi butuh [Node.js](https://nodejs.org) untuk menjalankan perintah `npm`.
